# 折光织界 · Lumenfold

折纸几何 × 折光割草肉鸽。人海清杂、连折爽感、局外永久解锁；支持**内网联机**与**外网联机**（主机权威）。

## 快速开始

```bash
npm install
npm start          # 仅静态页 http://localhost:5173
npm run lan        # 仅中继 ws://0.0.0.0:8787（内网）
npm run wan        # 页面 + 中继一体 http://0.0.0.0:8787 （适合外网部署）
```

### 内网联机
1. 一台机 `npm run lan`
2. 游戏里「内网联机」，填 `ws://局域网IP:8787`
3. 主机创建房间，他人填房间码加入

### 外网联机（推荐一体服）
1. 在有公网 IP 的机器 / 云服务器上：
   ```bash
   npm install
   npm run wan
   ```
2. 防火墙放行端口（默认 `8787`）
3. 所有人打开 `http://你的公网IP:8787/`，点「外网联机」→ 创建/加入房间  
   （同域会自动填中继地址）

若页面用 **HTTPS** 托管，中继必须是 **wss://**（见下方 TLS）。

也可在地址栏带参数：`?relay=wss://your.domain`

## 设计要点

- **割草向**：杂兵多、单体脆、弹速慢、准头差；精英极少
- **爽感**：穿透、连折加速、击杀顿帧与爆粒子
- **联机缩放**：人数↑ → 刷怪量/补波↑，血量小幅↑
- **折印平衡**：客机相对主机偏高则抑攻（最多约 28%），偏低则加韧/减伤
- **各自选折纹**：清房后每人按自己的解锁池独立三选一；主机选完若仍有人在选则最多等 5 秒
- **存档安全**：设备盐 + HMAC 签名（单机软防护）；尘入账限速；工坊扣尘与解锁原子写入
- **联机安全**：中继只转发并限流/限载荷；仅主机可下发 snapshot/start

## Docker 部署

```bash
docker build -t lumenfold .
docker run -p 8787:8787 -e LUMENFOLD_PUBLIC_WS=wss://your.domain lumenfold
```

环境变量：

| 变量 | 含义 |
|------|------|
| `LUMENFOLD_PORT` | 端口，默认 8787 |
| `LUMENFOLD_SERVE_STATIC` | `1` 托管页面（wan），`0` 仅中继（lan） |
| `LUMENFOLD_PUBLIC_WS` | 写入 `/relay-info` 的公网 wss 地址，供前端默认填入 |

## HTTPS / WSS（你需要做的）

浏览器在 **https** 页面上**禁止**连接 `ws://`。任选其一：

1. **反代**：Nginx / Caddy 把 `wss://域名` 转到本机 `8787`，并配证书  
2. **隧道**：Cloudflare Tunnel、frp、ngrok 等露出 wss  
3. **先用 HTTP**：`npm run wan` + `http://公网IP:8787`（无证书时最简单）

## 你需要准备什么

1. **一台能被好友访问的机器**（云主机 / 家里宽带+端口映射 / 隧道）
2. **放行端口**（默认 8787 TCP）
3. 若要用手机流量 / HTTPS 站点：准备 **域名 + TLS（wss）**
4. 好友打开同一网址，用房间码联机即可

账号系统、匹配大厅、反作弊权威服仍未做；当前外网 = 公网可达的同一套主机权威中继。
