# 折光织界 · Lumenfold

折纸几何 × 折光割草肉鸽。人海清杂、连折爽感、局外永久解锁；支持**内网联机**（主机权威），**外网接口已预留**。

## 快速开始

```bash
npm install
npm start          # http://localhost:5173
npm run lan        # 内网中继 ws://0.0.0.0:8787
```

联机：一台机跑 `npm run lan`，游戏里填 `ws://局域网IP:8787`，主机「创建房间」，其他人填房间码加入。

首次进入有引导教程；标题里可「再看教程」。

## 设计要点

- **割草向**：杂兵多、单体脆、弹速慢、准头差；精英极少
- **爽感**：穿透、连折加速、击杀顿帧与爆粒子
- **联机缩放**：人数↑ → 刷怪量/补波↑，血量小幅↑
- **存档安全**：设备盐 + HMAC 签名；尘入账限速；篡改则重置
- **联机安全**：中继只转发；仅主机可下发 snapshot/start

## 外网预留

`WanSession` 与内网同协议，未来换成正式 `wss` 匹配服 + 账号 token 即可，无需改战斗逻辑。
